# Phase 3.4.8 — React Patterns Intelligence

> Engineering contract: [`../../../AGENTS.md`](../../../AGENTS.md)

Status: ⏳ Planned

---

## Objective

Analyze common React ecosystem patterns and anti-patterns.

---

## Scope

### React Query

Conditional analysis for projects using React Query.

Potential areas:

- query key stability
- invalidation misuse
- mutation/query misuse
- unnecessary effects around query state
- stale query configuration

### Suspense

Detect:

- ineffective Suspense boundaries
- incorrect fallback patterns
- unsupported assumptions about loading state

### Error Boundaries

Detect missing or ineffective error boundaries where statically meaningful.

### Common React Anti-patterns

Detect high-confidence React anti-patterns that do not belong to another specialized intelligence module.

## Requirements

Framework/library-specific rules must activate only when the relevant dependency or API can be identified.
