# Phase 3.4.4 — React Rendering Intelligence

> Engineering contract: [`../../../AGENTS.md`](../../../AGENTS.md)

Status: ⏳ Planned

---

## Objective

Analyze React rendering behavior and detect avoidable rendering problems.

---

## Rules

### Unnecessary Re-render Detection

Detect:

- unstable values
- unnecessary state updates
- avoidable parent-driven renders
- render-triggering patterns

---

### Memo Misuse

Detect:

- unnecessary React.memo
- memoization that cannot provide value
- unstable props defeating memoization
- incorrect memo boundaries

---

### Callback Misuse

Detect:

- unnecessary useCallback
- unstable callbacks
- callbacks recreated unnecessarily
- dependency misuse

---

### Unstable Props

Detect:

- inline object creation
- inline array creation
- inline functions
- unstable derived props

Analyze whether the receiving component boundary makes the instability meaningful.

---

### Key Detection

Detect:

- missing keys
- unstable keys
- array-index keys where inappropriate
- duplicate key expressions where statically detectable

Every rule requires positive and negative fixtures.
