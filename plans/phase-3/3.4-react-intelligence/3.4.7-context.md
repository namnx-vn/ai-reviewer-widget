# Phase 3.4.7 — React Context Intelligence

> Engineering contract: [`../../../AGENTS.md`](../../../AGENTS.md)

Status: ⏳ Planned

---

## Objective

Analyze React Context usage for architectural and rendering performance issues.

---

## Rules

### Context Performance

Detect unstable provider values and avoidable consumer invalidation.

### Provider Nesting

Detect unnecessarily deep or duplicated provider composition where statically identifiable.

### Unstable Context Values

Detect object/function values recreated on every provider render.

---

## Requirements

Use semantic provider/value analysis.

Do not report performance issues without sufficient static evidence.
