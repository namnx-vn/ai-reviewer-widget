# Phase 3.4.9 — Next.js Intelligence

> Engineering contract: [`../../../AGENTS.md`](../../../AGENTS.md)

Status: ✅ Complete

---

## Objective

Add Next.js-specific React intelligence without coupling the core React engine to Next.js.

---

## Scope

### App Router

Analyze:

- server/client boundaries
- client component placement
- unsupported client/server patterns

### Next.js React Rules

Detect framework-specific misuse only when Next.js usage is established.

---

## Architecture

Next.js rules must be implemented as an optional plugin.

The core React engine must remain framework-agnostic.

## Delivered

- Exported an opt-in `nextjsPlugin`; the default React plugin remains framework-agnostic.
- Added deterministic App Router rules for client hooks and event handlers in Server Components, server-only imports in Client Components, async Client Components, and invalid `"use client"` placement.
- Limited analysis to `app/` paths so React code is not treated as Next.js code without App Router evidence.
- Added regression coverage for every rule and the optional-plugin boundary.
