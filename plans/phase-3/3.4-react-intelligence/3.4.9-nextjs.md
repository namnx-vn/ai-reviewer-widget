# Phase 3.4.9 — Next.js Intelligence

> Engineering contract: [`../../../AGENTS.md`](../../../AGENTS.md)

Status: ⏳ Planned

---

## Objective

Add Next.js-specific React intelligence without coupling the core React engine to Next.js.

---

## Scope

### App Router

Analyze:

- server/client boundaries
- client component placement
- unsupported client/server patterns

### Next.js React Rules

Detect framework-specific misuse only when Next.js usage is established.

---

## Architecture

Next.js rules must be implemented as an optional plugin.

The core React engine must remain framework-agnostic.
