# Phase 3.4.5 — React State Intelligence

> Engineering contract: [`../../../AGENTS.md`](../../../AGENTS.md)

Status: ⏳ Planned

---

## Objective

Analyze React state modeling, mutation, derivation, and synchronization.

---

## Rules

### State Mutation

Detect direct mutation of:

- state objects
- state arrays
- nested state values

---

### Derived State

Detect state that can be deterministically derived from existing props/state.

---

### Redundant State

Detect duplicated state representing the same source of truth.

---

### State Synchronization

Detect unnecessary synchronization effects and state synchronization loops.

---

## Requirements

Rules must use semantic analysis instead of syntax-only heuristics.

Each rule requires:

- severity
- confidence
- suggestion
- location
- positive fixtures
- negative fixtures
- regression tests
