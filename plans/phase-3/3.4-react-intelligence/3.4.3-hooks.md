# Phase 3.4.3 — React Hooks Intelligence

> Engineering contract: [`../../../AGENTS.md`](../../../AGENTS.md)

Status: ✅ Complete

---

## Objective

Detect correctness and lifecycle problems in React Hooks using the semantic infrastructure from Phase 3.4.2.

---

## Rules

### react.hooks.missing-deps

Detect missing dependencies in:

- useEffect
- useMemo
- useCallback
- supported custom hooks where dependency semantics are known

Requirements:

- dependency extraction
- scope-aware reference analysis
- dependency comparison
- false-positive protection

---

### react.hooks.stale-closure

Detect closures capturing values that may become stale.

Analyze:

- effects
- callbacks
- asynchronous callbacks
- timers
- event subscriptions

---

### react.hooks.conditional

Detect Hooks executed conditionally.

Examples:

- if statements
- conditional expressions
- logical expressions
- early returns before Hook calls
- loops

---

### react.hooks.invalid-order

Detect violations of the Rules of Hooks.

Analyze:

- conditional execution
- nested functions
- loops
- callbacks
- component boundaries
- custom hook boundaries

---

### react.hooks.unnecessary-effect

Detect effects used for derived state or synchronous calculations that should not require an effect.

Examples:

- derived values
- synchronous state synchronization
- calculations that can run during render

---

### react.hooks.async-effect

Detect unsafe asynchronous effects.

Analyze:

- async effect callbacks
- stale async state
- missing cancellation
- race conditions
- cleanup handling

---

## Requirements

Every rule must include:

- detection
- ReviewFinding
- severity
- confidence
- suggestion
- source location
- positive tests
- negative tests
- regression fixtures
