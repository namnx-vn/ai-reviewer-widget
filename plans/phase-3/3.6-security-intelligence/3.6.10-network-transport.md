# Phase 3.6.10 — Network & Transport Security

> Parent: [Security Intelligence](./README.md)

Status: ✅ Complete

## Objective
Detect deterministic insecure transport, TLS, proxy, and CORS configuration patterns.

## Dependencies
- 3.6.0
- Profiles in 3.6.22 may alter severity/context policy

## Rules
```text
security.network.insecure-http
security.network.insecure-websocket
security.network.tls-verification-disabled
security.network.weak-tls
security.network.permissive-cors
security.network.credentials-wildcard-origin
security.network.untrusted-proxy
```

## Detection Contract
Model relevant Node/browser configuration shapes and explicit transport APIs. `rejectUnauthorized: false` is high-severity evidence. Localhost/dev URLs must not automatically receive production severity unless configuration/profile context supports it.

## Tests
HTTP/HTTPS, WS/WSS, TLS options, CORS wildcard/credentials combinations, trusted proxy settings, dev/localhost cases, dynamic configs, aliases, and safe cases.

## Exit Criteria
Transport findings separate observable configuration from environment/policy interpretation.
