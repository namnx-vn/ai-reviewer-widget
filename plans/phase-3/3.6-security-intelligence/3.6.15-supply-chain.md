# Phase 3.6.15 — Supply Chain Security

> Parent: [Security Intelligence](./README.md)

Status: ✅ Complete

## Objective
Provide deterministic repository-level supply-chain checks without coupling core analysis to remote vulnerability services.

## Dependencies
- 3.6.0
- Repository/package metadata access through existing analyzer boundaries

## Rules
```text
security.supply-chain.git-dependency
security.supply-chain.http-dependency
security.supply-chain.install-script
security.supply-chain.dynamic-require
security.supply-chain.lockfile-missing
security.supply-chain.unpinned-critical-source
```

## Detection Contract
Core checks work offline. External CVE/advisory lookup is not an AST rule and must later live behind separate dependency-intelligence adapters (for example OSV, GitHub Advisory DB, SBOM, npm audit integrations).

## Tests
Package manifests, lockfile presence, git/http dependencies, lifecycle scripts, dynamic require/import cases, pinned/safe sources, monorepo edge cases, and deterministic repository scanning.

## Exit Criteria
No network service is required for core supply-chain findings; remote advisory data is architecturally separate.
