# Phase 3.6.16 — JavaScript Object Security

> Parent: [Security Intelligence](./README.md)

Status: ⏳ Planned

## Objective
Detect prototype pollution and dangerous attacker-controlled object mutation patterns.

## Dependencies
- 3.6.0
- 3.6.19 for tainted key/value/object tracking

## Rules
```text
security.object.prototype-pollution
security.object.unsafe-deep-merge
security.object.untrusted-dynamic-key
security.object.constructor-prototype
security.object.unsafe-object-assign
```

## Detection Contract
Track attacker-controlled key, value, and object dimensions independently where necessary. Recognize `__proto__`, `constructor.prototype`, unsafe recursive merge/copy patterns, and tainted computed property writes. Do not flag every computed property assignment.

## Tests
Direct prototype paths, tainted keys, safe allowlisted keys, object merges, recursive merges, constants, sanitization/guard cases, aliases, and false positives.

## Exit Criteria
Object-security rules use shared taint primitives and demonstrate low noise for normal computed properties.
