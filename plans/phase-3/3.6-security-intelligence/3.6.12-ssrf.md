# Phase 3.6.12 — SSRF Intelligence

> Parent: [Security Intelligence](./README.md)

Status: ⏳ Planned

## Objective
Detect attacker-controlled network targets reaching server-side request sinks.

## Dependencies
- 3.6.0
- 3.6.19
- 3.6.20 for wrapped request clients

## Rules
```text
security.ssrf.untrusted-request
security.ssrf.metadata-endpoint
security.ssrf.local-network
security.ssrf.localhost
security.ssrf.unsafe-redirect
security.ssrf.weak-host-validation
```

## Detection Contract
Model request/body/query/param/header sources and explicit request sinks such as `fetch`, `axios`, `http.request`, and `https.request` via centrally defined adapters. Model protocol allowlists, hostname allowlists, IP classification, and redirect restrictions. Naive substring hostname checks must not count as strong validation.

## Tests
Direct and propagated URLs, metadata addresses, loopback/private ranges where statically known, hostname allowlists, protocol guards, redirects, wrong validation, constants, and wrapper clients.

## Exit Criteria
SSRF rules emit source-to-request evidence and distinguish strong validation from weak string checks.
