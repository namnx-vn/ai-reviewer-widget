# Phase 3.6.13 — Security Configuration

> Parent: [Security Intelligence](./README.md)

Status: ⏳ Planned

## Objective
Detect insecure application/security configuration with explicit environment/context handling.

## Dependencies
- 3.6.0
- 3.6.22 may provide stricter profile interpretation

## Rules
```text
security.config.debug-enabled
security.config.production-stacktrace
security.config.cors-wildcard
security.config.default-credential
security.config.unsafe-csp
security.config.production-source-map
security.config.admin-interface
security.config.development-mode
```

## Detection Contract
Configuration findings require semantic context. A source map, debug flag, or permissive setting must not automatically be reported as production exposure unless environment/profile context supports it. Detection should extract facts; policy should interpret risk.

## Tests
Production/dev config variants, CSP directives, CORS, default credentials, stack trace/debug options, source-map settings, dynamic configs, and profile behavior.

## Exit Criteria
Configuration facts are deterministic and separate from environment-specific severity policy.
