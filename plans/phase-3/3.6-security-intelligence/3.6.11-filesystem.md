# Phase 3.6.11 — Filesystem & Resource Security

> Parent: [Security Intelligence](./README.md)

Status: ⏳ Planned

## Objective
Detect untrusted filesystem access, path traversal, unsafe extraction/upload, and related resource risks.

## Dependencies
- 3.6.0
- 3.6.19 required for path-taint analysis
- 3.6.20 for cross-function paths

## Rules
```text
security.filesystem.path-traversal
security.filesystem.arbitrary-read
security.filesystem.arbitrary-write
security.filesystem.unsafe-upload
security.filesystem.unrestricted-upload
security.filesystem.zip-slip
security.filesystem.insecure-temp-file
security.filesystem.symlink-risk
```

## Detection Contract
Path traversal requires evidence of untrusted path material reaching a filesystem sink. Model contextual mitigations such as canonical resolution, strict root containment, and allowlists. `path.basename()` must not be treated as a universal sanitizer for every filesystem use.

## Tests
Read/write sinks, path join/resolve, traversal segments, upload names, archive entries, containment checks, allowlists, constants, wrong/incomplete sanitizers, and multi-hop flows.

## Exit Criteria
Filesystem findings use shared typed path taint and sink-aware validation.
