# Phase 3.5 — Micro Frontend Intelligence

> Engineering contract: [`../../../AGENTS.md`](../../../AGENTS.md)

Status: ✅ Complete

---

## Objective

Build static intelligence for Micro Frontend architectures, with React as the primary supported framework.

## Delivered

- Added a standalone `src/mfe` analysis layer that consumes the repository dependency graph without coupling MFE rules to React intelligence.
- Detects remotes that depend on host implementation, host deep imports into remote internals, and unsafe Module Federation React/react-dom sharing.
- Detects statically visible React/react-dom shared-version major mismatches.
- Integrates deterministic MFE findings into normal file and pull-request reviews as architecture findings.

---

## Scope

### React Boundaries

- host/remote boundaries
- component ownership
- cross-boundary imports
- shared state risks

### Module Federation

- remote configuration
- shared dependencies
- singleton requirements
- version mismatch risks

### Remote Contracts

- public API boundaries
- incompatible contracts
- unsafe cross-application coupling

### Shared Dependencies

- duplicate React versions
- incompatible shared packages
- singleton violations

### Runtime Boundaries

- remote loading risks
- boundary violations
- unsafe dependency direction

---

## Architecture

Micro Frontend analysis must be implemented as a separate intelligence layer.

The React Intelligence Engine may provide reusable semantic utilities, but Micro Frontend-specific rules must not be coupled into the React core.
