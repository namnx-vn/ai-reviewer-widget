# Phase 3.7.4 — Image & Asset Performance

> Parent: [Phase 3.7](./README.md)

Status: ⏳ Planned

## Objective

Detect source-level image and asset delivery anti-patterns without pretending to know runtime transfer size when metadata is unavailable.

## Rules

```text
performance.image
performance.image.missing-lazy
performance.image.missing-dimensions
performance.image.oversized-source-pattern
performance.asset.eager-noncritical
```

## Detection Contract

Use JSX/HTML semantics where available. Distinguish critical above-the-fold assets from generic assets only when evidence exists; otherwise use conservative confidence.

## Tests

Cover img elements, dynamic sources, lazy loading attributes, dimensions, repeated large asset imports where known, safe assets, and TSX fixtures.
