# Phase 3.7.17 — Interprocedural Performance Analysis

> Parent: [Phase 3.7](./README.md)

Status: ⏳ Planned

## Dependency

Requires 3.7.16.

## Objective

Propagate performance summaries across function and module boundaries.

## Rollout

```text
A. local call graph
B. parameter-to-operation summaries
C. return-cost summaries
D. same-file summaries
E. cross-file import/export summaries
F. framework/library adapters
```

Example summary concepts:

```text
parameter 0 controls iteration size
function performs network call
function returns database result
function invokes callback repeatedly
function contains blocking CPU operation
```

## Safety Controls

Set deterministic configurable limits for recursion, cycles, call depth, path count, and summary size.

Unknown calls MUST remain unknown; do not invent a cost or silently assume they are free.

## Tests

Cover wrappers, return propagation, cross-function loops, recursive cycles, imports/exports, aliases, callbacks, and limit behavior.
