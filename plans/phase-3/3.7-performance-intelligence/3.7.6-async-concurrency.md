# Phase 3.7.6 — Async & Concurrency Performance

> Parent: [Phase 3.7](./README.md)

Status: ✅ Complete

## Objective

Detect unbounded concurrency, accidental serialization, and fan-out patterns that can exhaust resources or inflate latency.

## Rules

```text
performance.async.serial-await
performance.async.unbounded-promise-all
performance.async.unbounded-concurrency
performance.async.promise-created-in-loop
performance.async.fire-and-forget-resource-work
```

## Detection Contract

Differentiate bounded static arrays from attacker/data-sized collections. `Promise.all` over a small literal list is not unbounded concurrency.

## Tests

Cover loops, map + Promise.all, static arrays, bounded chunking, concurrency-limit helpers where modeled, sequential dependencies, and false-positive regressions.
