# Phase 3.7.7 — Memory & Resource Safety

> Parent: [Phase 3.7](./README.md)

Status: ✅ Complete

## Objective

Detect source patterns that can retain memory or operating resources without bounds.

## Rules

```text
performance.memory.unbounded-cache
performance.memory.unbounded-map-set
performance.memory.listener-leak
performance.memory.timer-leak
performance.memory.large-buffer-retention
performance.resource.missing-cleanup
```

## Detection Contract

Prefer lifecycle evidence. A Map or Set is not inherently a leak; findings require persistent scope plus unbounded growth or missing cleanup evidence.

## Tests

Cover module-level caches, bounded caches, cleanup functions, React effect cleanup where applicable, timers, event listeners, streams/resources, and safe local collections.
