# Phase 3.7.13 — Backpressure & Rate Control

> Parent: [Phase 3.7](./README.md)

Status: ⏳ Planned

## Objective

Detect producers, queues, streams, and request fan-out that can grow faster than consumers can safely process.

## Rules

```text
performance.backpressure.unbounded-queue
performance.backpressure.unbounded-producer
performance.backpressure.missing-stream-control
performance.backpressure.missing-concurrency-limit
performance.rate-control.hot-loop-external-call
```

## Detection Contract

Do not report merely because arrays or queues exist. Findings require growth/producer semantics plus absent bound, drain, pause, limiter, or batch evidence.

## Tests

Cover queue push/consume patterns, stream pause/resume, concurrency pools, bounded buffers, workers, hot loops, and false-positive local arrays.
