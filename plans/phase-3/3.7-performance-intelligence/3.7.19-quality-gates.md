# Phase 3.7.19 — Performance Quality Gates

> Parent: [Phase 3.7](./README.md)

Status: ⏳ Planned

## Objective

Convert deterministic performance findings into CI/PR policy decisions without coupling analysis to GitHub.

## Gate Inputs

```text
severity
confidence
profile
new/existing baseline state
critical-path membership
rule category
approved suppression
```

## Recommended Banking Defaults

```text
new critical-path high-confidence high/critical finding → fail
new unbounded resource/concurrency finding             → fail
new retry/timeout critical-path finding                → fail or configured block
medium findings                                        → configurable
legacy findings                                        → baseline
```

## Baseline Principle

Prefer blocking newly introduced regressions instead of making adoption impossible on legacy repositories.

## Suppression

Suppressions must be auditable and tied to rule/fingerprint/reason, with optional expiry. Silent generic ignore comments are not acceptable as the long-term model.

## Output

Return domain-level `pass | warn | fail` plus deterministic reasons. GitHub integration decides presentation.

## Tests

Cover baseline, new findings, profile overrides, critical paths, confidence thresholds, suppressions, and deterministic decision ordering.
