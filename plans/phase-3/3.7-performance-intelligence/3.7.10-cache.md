# Phase 3.7.10 — Cache Intelligence

> Parent: [Phase 3.7](./README.md)

Status: ⏳ Planned

## Objective

Detect cache designs that create memory growth, stampedes, stale financial data risk, or redundant recomputation.

## Rules

```text
performance.cache.unbounded
performance.cache.missing-ttl
performance.cache.stampede-risk
performance.cache.recompute-on-miss
performance.cache.critical-data-without-freshness-policy
```

## Banking Constraint

Sensitive-data confidentiality remains Phase 3.6 responsibility. Phase 3.7 focuses on performance/freshness behavior and may reference security metadata without duplicating security rules.

## Tests

Cover in-memory caches, TTL configuration, single-flight patterns, cache misses, bounded LRU-like semantics when modeled, and critical financial-data freshness profiles.
