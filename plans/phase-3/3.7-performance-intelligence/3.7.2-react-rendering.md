# Phase 3.7.2 — React Rendering Performance

> Parent: [Phase 3.7](./README.md)

Status: 🚧 In progress

## Objective

Extend existing React semantic intelligence with deterministic render-cost findings without duplicating Phase 3.4 logic.

## Rules

```text
performance.large-component
performance.react.unstable-prop
performance.react.expensive-render-computation
performance.react.list-with-heavy-child
performance.react.context-broad-rerender
performance.react.repeated-derived-computation
```

## Architecture Boundary

React-specific detection MUST live under the React intelligence boundary and reuse existing component, JSX, scope, declaration, and rendering analysis.

Generic performance infrastructure MUST NOT import React modules.

## Noise Control

Do not flag a component merely by line count. `large-component` should use structural evidence such as JSX complexity, nested branches, repeated expensive work, or configurable thresholds.

## Tests

Include function/arrow components, memoized cases, stable/unstable props, list rendering, context consumers, false-positive regressions, and TSX fixtures.
