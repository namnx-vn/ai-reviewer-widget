# Phase 3.7.5 — Network & Request Efficiency

> Parent: [Phase 3.7](./README.md)

Status: ⏳ Planned

## Objective

Detect avoidable request waterfalls, duplicate calls, missing request coalescing opportunities, and inefficient network structures.

## Rules

```text
performance.network-waterfall
performance.network.sequential-independent-requests
performance.network.duplicate-request
performance.network.request-in-loop
performance.network.excessive-roundtrips
```

## Detection Contract

Only label calls independent when data dependencies prove they can run concurrently. Do not transform every sequential await into a finding.

`performance.network-waterfall` from the original plan remains represented here.

## Tests

Include dependent vs independent awaits, loop requests, repeated URLs/callees, branch-dependent calls, Promise.all safe cases, and wrapper functions when supported.
