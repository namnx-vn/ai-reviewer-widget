# Phase 3.7.1 — Bundle & Dependency Efficiency

> Parent: [Phase 3.7](./README.md)

Status: 🚧 In progress

## Objective

Detect dependency and import structures that unnecessarily increase shipped code or duplicate runtime cost.

## Rules

```text
performance.large-import
performance.duplicate-dependency
performance.barrel-overimport
performance.heavy-library-whole-import
performance.duplicate-runtime-library
```

## Detection Contract

Prefer import/dependency semantics over raw text matching. Distinguish type-only imports, test-only dependencies, dynamic imports, and runtime imports where repository context allows.

Do NOT infer actual bundle byte size unless reliable metadata exists. Static findings should describe structural risk rather than fabricate size numbers.

## Tests

Cover direct imports, named imports, type imports, barrels, aliases, repeated package versions where package metadata is available, and false-positive fixtures.

## Exit Criteria

Original `performance.large-import` and `performance.duplicate-dependency` intents are preserved with deterministic evidence.
