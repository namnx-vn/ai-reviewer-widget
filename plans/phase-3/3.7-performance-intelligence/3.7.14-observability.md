# Phase 3.7.14 — Observability & Performance Telemetry

> Parent: [Phase 3.7](./README.md)

Status: 🚧 In progress

## Objective

Provide deterministic checks for observability around critical performance boundaries where application semantics are known.

## Candidate Rules

```text
performance.observability.critical-path-without-latency-boundary
performance.observability.external-call-without-timing-context
performance.observability.retry-without-attempt-context
```

## Important Scope Rule

Do NOT attempt to enforce generic logging/metrics presence across arbitrary code. Rules should activate only for modeled critical paths or configured telemetry adapters.

Security-sensitive logging remains Phase 3.6.

## Tests

Cover configured telemetry wrappers, critical-path annotations, external calls with timing spans, wrappers, and unconfigured generic functions.
