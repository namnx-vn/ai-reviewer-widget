# Phase 3.7.8 — CPU & Algorithmic Hotspots

> Parent: [Phase 3.7](./README.md)

Status: 🚧 In progress

## Objective

Detect deterministic CPU-heavy structures in hot or repeated paths.

## Rules

```text
performance.algorithm.nested-loop-hotpath
performance.algorithm.repeated-linear-search
performance.algorithm.repeated-sort
performance.algorithm.expensive-regex-loop
performance.algorithm.repeated-serialization
```

## Detection Contract

Do not claim formal Big-O complexity beyond what is structurally provable. Prefer evidence such as nested iteration over the same data, repeated sort/filter/find within loops, or repeated serialization.

## Tests

Include small constant loops, dynamic collections, nested loops, indexed lookup alternatives, repeated sort/search, and false-positive cases.
