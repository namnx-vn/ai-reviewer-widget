# Phase 3.7.9 — Database & Persistence Efficiency

> Parent: [Phase 3.7](./README.md)

Status: ✅ Complete

## Objective

Detect database and persistence access patterns with deterministic latency/scalability risk.

## Rules

```text
performance.database.query-in-loop
performance.database.n-plus-one
performance.database.unbounded-query
performance.database.missing-pagination
performance.database.repeated-identical-query
performance.database.transaction-roundtrip
```

## Architecture

Database APIs MUST be modeled through adapters/summaries rather than generic function-name substring matching.

## Noise Control

Do not flag every query in an iterator when batching or bounded concurrency is proven. Missing pagination requires collection-returning query semantics, not merely any DB call.

## Tests

Cover query loops, batching, pagination, limit/take patterns, repeated queries, ORM adapters, and safe cases.
