# Phase 3.7.3 — Loading & Code Splitting

> Parent: [Phase 3.7](./README.md)

Status: ⏳ Planned

## Objective

Detect high-cost eager loading where lazy loading or route/component splitting is structurally appropriate.

## Rules

```text
performance.missing-lazy
performance.eager-heavy-route
performance.eager-optional-feature
performance.dynamic-import-inside-hotpath
```

## Detection Contract

Do not recommend lazy loading for tiny modules solely because they are imported synchronously. Findings require evidence of optional/route-level/heavy dependency boundaries.

Preserve original `performance.missing-lazy` intent.

## Tests

Cover React.lazy, dynamic import, route-level components, conditional feature modules, repeated dynamic imports, type-only imports, and safe eager imports.
