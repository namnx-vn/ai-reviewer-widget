# Phase 3.7.0 — Performance Architecture Foundation

> Parent: [Phase 3.7](./README.md)

Status: 🚧 In progress

## Objective

Create stable domain contracts and registries for all later performance analysis.

## Deliverables

Define typed concepts for:

```text
PerformanceRule
PerformanceRuleMeta
PerformanceRuleContext
PerformanceFinding
PerformanceCategory
PerformanceSeverity
PerformanceConfidence
PerformanceEvidence
PerformanceCostKind
PerformanceOperation
PerformancePathStep
PerformanceProfile
```

Create a deterministic rule registry with duplicate-ID rejection, stable ordering, enable/disable support, and policy lookup.

Finding IDs MUST derive from stable data such as rule ID, file path, node range, and operation kind. Random IDs, timestamps, or global mutable counters are prohibited.

## Shared Analysis Context

Design the context so later rules can reuse parsed AST, scope/declaration data, import graph, call graph, and cost summaries without reparsing files per rule.

## Tests

- rule registration;
- duplicate IDs;
- stable IDs;
- stable ordering;
- metadata validation;
- empty/multiple finding output;
- context reuse contract.

## Exit Criteria

Foundation contracts are stable and no real performance rule is required yet.

## Out of Scope

Bundle rules, cost propagation, call graph analysis, runtime measurement, and quality gates.
